## 三 纪律与指向

**阶段纪律**：占位（待调研）→ 调研 → 定方案 → 实现（中途出现实现分叉当场问、当场记 `Verdict/`）→ 修 bug 与优化（**脚本自测 + 实际客户端测试，两步都不许跳**）→ 记录（每大点两篇进 `Done/`）。**阶段推进只凭用户口令**，助手不得以「调研已充分」为由自行补 ③ 段或开工。

**调研期纪律**：不动代码、不改数据；取证只做只读探测。

**环境纪律**（本机）：

- 跑项目脚本显式用 `.venv/Scripts/python.exe`（Python 3.11.15），先 `unset PYTHONPATH`；
- 装包只许 `uv pip install`，**禁 `uv add` / `uv sync`**（会整批卸掉不在 lock 里的手动包：torch、sentence-transformers、chromadb、pywebview、pystray、pillow）；
- 涉及端口：用户桌面壳常驻 8123（被占自动后移），助手自起服务用 8130/8131 且用毕即 kill，不碰用户正在运行的进程。

**数据与凭据纪律**：

- 改用户数据要**先备份 + 明确授权**；真实账号只读；需要账号时用 `t_*` 临时账号并跑完自清；
- 凭据真实值只在 `.env`（改动前先备份 `.env.bak_<时间戳>`），界面与接口只回显键名/掩码；
- 写能力口径：内置写工具（工作目录 create/edit/delete）纯文字可用；自配来源的写操作要「/」选中对应写工具集；写池 CLI 的只读命令也不进路由池与 Agent 简报。

**检索额度**：每轮检索限定 15 次（Tavily 每月 1 日重置）。2026-10-30 本轮已用满 15 次，02 / 03 的补充取证留下一轮，或就地读源码完成。

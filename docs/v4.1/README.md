## 这一版带来什么

> 一句话主线：**把助手从窗口里放出来，放到桌面上** —— 一个随时能点的球；需要时它能**看见你的屏幕**，并在你允许的范围内**替你点两下**。

四个大点按顺序落地：悬浮球外壳（对话入口）→ 屏幕共享（看）→ 屏幕控制（看 + 动）→ 浮窗与桌宠（好看、好懂）。

---

### 一、桌面上多了一个球（大点 01）

- **登录之后才出现**，退出登录立刻收起；没登录时桌面上不会有它。
- **点一下**弹出迷你对话窗：能选会话、能发消息、能看回答 —— 只有对话，**不是把主窗口缩小**。
- **按住拖**到顺手的位置，下次登录还回到那儿；也可以设一个全局快捷键呼出。
- 主窗口收进托盘时，球还在，随时能问一句。

### 二、让它看得见你的屏幕（大点 02）

在会话里打开「🖥 屏幕共享」，它就能在你需要时**自己判断该看一眼屏幕**：

- 只在**你开着这个开关的会话里**有这个能力；关掉就是彻底没有（模型连这件工具都看不到）。
- 抓图由**桌面外壳**完成：拍的**那一瞬间**把你的主窗、浮窗、球都藏起来再拍，拍完立刻还原 —— 所以它看到的是你的屏幕，不是它自己。
- **你自己按 `Win+Shift+S` 截图不受影响**，看到的还是完整桌面。
- 截图只在本轮内存里用，**不进对话历史**（不会越聊越慢）。

### 三、让它能动手（大点 03）

再打开「🖱 屏幕控制」，它就能在**你允许的窗口**里替你操作：

| 能做什么 | 怎么用 |
|---|---|
| 点击 / 双击 | 说「点右上角那个按钮」 |
| 打字 | 中文也可以（走剪贴板粘贴，不和输入法打架） |
| 按键 | 回车、Esc、Tab、方向键、翻页等 |
| 滚轮 | 「往下翻，找到新加坡节点」 |

四道闸让它不会乱来：

1. **两档开关**：只看、或看 + 动，按会话分别开；
2. **每轮动作上限**（默认 20 次）：做完就停，不会一直点下去；
3. **只认最新那一帧**：它必须先看、再动；界面变了就得重新看 —— 避免「照着旧截图点新界面」；
4. **窗口白名单**：只有你在设置里勾过的程序（默认 `python.exe`，可加 Edge、微信等）才接受点击和打字，其它窗口直接拒绝。

另外两个体验上的改动：

- **小图标先放大再看**：标题栏那种小按钮，它会先截一小块放大确认位置再点，点偏的概率明显下降；
- **只留电脑操作工具**：这个模式下模型手上只有「看 / 点 / 打 / 按 / 滚」五件工具，**速度更快**，也不会忽然跑去查别的资料。

> 明确不做：后台静默操作、锁屏状态下操作、批量给陌生账号发消息。

### 四、浮窗更好看，球变成了桌宠（大点 04）

- **浮窗配色对齐主窗**：浅绿纸面、墨绿气泡是你的助手、绿色气泡是你；发送键有和主窗一样的扩散动效。
- **浮窗可以单独换背景**：主窗背景按钮里多了「主窗背景 / 浮窗背景」两档，各存各的，互不影响。
- **球会动了**：待机时会换姿势、在桌面工作区里**随机小幅走动**；鼠标靠近就停下；按住能拖；点一下打开面板。觉得太快或太闹，可以在设置里**调尺寸**、**关掉自主走动**。
- 刚开面板那几秒它会摆出「等你打字」的姿势，5 秒没输入就自己回去走动。

## 升级与兼容

- **需要重启桌面壳**（这一版全部改动都在外壳与前端；后端接口是加法，不重启也能跑旧版外壳）。
- 旧数据不动：账号、会话、画像、技能、CLI 配置、知识库都沿用。
- **新增设置项**（设置页）：
  - 屏幕共享：每轮截图张数上限（1~50）、截图长边、JPEG 质量、小目标判定像素；
  - 屏幕控制：每轮动作上限（默认 20）、窗口白名单；
  - 悬浮球：开关、尺寸（32~128，默认 80）、不透明度、快捷键、**自主走动**。
- 密钥仍只放 `.env`，界面不回显。

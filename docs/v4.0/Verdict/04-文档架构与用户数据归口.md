## 裁定 2（2026-10-13）：设置模块的载体与敏感操作口径（议题二 / 三）

| 项 | 内容 |
|---|---|
| 分叉点 | 议题二（账号绑定邮箱 + 一键注销）与议题三（把没进 `.env` 的开关收进表单）都要定「落点」与「载体」 |
| **裁定结果（载体）** | **分流**：开关 / 参数 → 库表 `app_settings`（保存即生效；读取带 2 秒缓存 + `reload()`）；**密钥 → 仍写 `.env`**（明文不进库、接口回传**永远只给掩码**），写入前自动备份 `.env.bak_<时间戳>` 并保留注释与其余行 |
| **裁定结果（注销语义）** | **硬删**（用户口径「一键账号注销」+ 复用整账号清理经验），三重校验：**账号密码 + 绑定邮箱验证码 + 原样输入确认词「注销账号」**；执行前**先快照**到 `docs/v4.0/backups/account_delete_<账号>_<时间戳>/`，再走 `purge_account`（库行 + 文件侧 + `sessions`），随后旧 token 立即失效 |
| **裁定结果（验证码与绑定）** | 6 位数字、**只存哈希**（sha256 + pepper）、有效期 5 分钟、同用途 60 秒重发限制、最多试错 5 次；邮箱**唯一**（一邮箱只能绑一个账号）；换绑＝**先解绑（密码 + 旧邮箱码）再绑定**（单一安全路径） |
| **裁定结果（发信通道）** | **配置导向**（用户既有偏好「不写死厂商」）：`utils/mailer.py` 用标准库 smtplib，主机/端口/SSL/账号/发件名/授权码逐字段可配；`MAIL_DEBUG=1` 为**调试模式**（不发信、把验证码写 `tests/test_out/_mail_outbox.log`），供本机联调与自动化测试 |
| **裁定结果（上表单的键）** | 开关 **9 项**：`ASR_ENABLED` `DECISION_CACHE_ENABLED` `DECISION_AUDIT_SEEN` `DECISION_ALLOW_NONE` `ZX_STREAM` `ZX_ASSEMBLY_SOURCES` `TOOL_CALL_LOG_ENABLED` `AGENT_ERROR_LOG_ENABLED` `DS_DEBUG_PROMPTS`；决策模型参数 **8 项**（触发策略 / 近分阈值 / 精排候选数 / 超时 / 重试 / 日额度 / 会话额度 / 缓存时效）；邮件 **7 项**；只读密钥 **2 项**（掩码展示） |
| 附带裁定 | ① 两个日志开关用**新键** `*_ENABLED`（默认开），不改 `TOOL_CALL_LOG` / `AGENT_ERROR_LOG` 原本的「路径」语义；② `DS_DEBUG_PROMPTS` 由「打到 stdout」改为**写文件** `data/audit/prompts_dump.txt`（原写法在中文 Windows 重定向时遇 emoji 会崩，`agent/prompts.py:28` 有事故记录）；③ `decision_router._env()` 作为**唯一读取口**改问 `utils.settings`，一处改动即覆盖该模块全部开关与参数；④ 少数「导入期读取」的键（`ZX_ASSEMBLY_SOURCES`）由 `settings.apply_runtime_hooks()` 保存时**热更**，无需重启 |

## 裁定 2（2026-10-09）：题库 `city-climate` 按工具实际能力改判

| **可选方案** | **A** 改判类别为「噪声」（气候问答走世界知识/联网，池内无正解）；**B** 保持原状（把「城市相关的问法」都算 city 工具）；**C** 保留原题、另加一条覆盖 city 工具正常问法的题；**D** 先不动 |

## 裁定 3（2026-10-09）：`Z_STRONG` 由 2.4 重标定为 3.3

| 项 | 内容 |
|---|---|
| **分叉点** | 收口后唯一越线的立项条件是「噪声假阳性 0.143 > 0.1」，由**唯一 1 道题**（`city-climate`，z = 3.22）造成。调阈值治它，还是留着？ |
| **可选方案** | **A** 提到 3.3（消掉那 1 例；四个质量指标不变；代价是 3 道真命中题改回退全量）；**B** 保持 2.4（省上下文，接受 1 例）；**C** 先固化 `--sweep` 再定；**D** 下一轮再说 |
| **裁定结果** | **A**：`Z_STRONG = 3.3` |
| **依据** | 用户既有取舍口径（2026-09-27 定 2.4 时的原话）：**宁可多花上下文，也不要「自信地选错」**；且本次代价远小于上次（上次灰区翻倍，这次只多 3 道非噪声题、质量指标一个不变） |
| **影响面** | `tools/tool_router.py:41` 常量 + 标定注释（含本次数字与两次标定历史）；**两个口径都重跑**；`router_bench_baseline.json` 与 `router_bench_regressions.json` 的 `baseline_metrics` 再重写一次（`noise_false_positive` 0.143 → 0.000，`gray_ratio_nonnoise` 0.087 → 0.217） |

**副作用（如实记录，非新问题）**：本次重标定让「非噪声灰区题 ≥ 5 道」这条立项线**由「否」变「成立」**（2 道 → 5 道）—— 这是「更严阈值」的必然代价。此刻 Jev 的收益性质随之改变：那 5 道题在回退全量下**全部命中**（`hit@3 = 1.000`），所以 Jev 能带来的是「把注入从全量收窄到精确」（≈11.6k → ≈2.4k 字符/题），属**上下文成本**而非答案质量。这一点是**下一个大点（若做 Jev）的立项前提**，不是本大点的遗留问题。

## 裁定 5（2026-10-09）：`Z_STRONG` 定为 **3.8**（覆盖裁定 3 的 3.3）

| 项 | 内容 |
|---|---|
| **分叉点** | 素材批落地后，`Z_STRONG` 该取多少？（裁定 3 定的是 3.3；素材改动把 `city-climate` 的 z 顶到 冻结池 3.59 / 真机池 3.62） |
| **可选方案** | 3.4（我当时按冻结池证据提的）/ 3.62（真机最小可行，但贴边）/ **3.8**（两池都在平台区、离边界留余量）/ 4.0（余量最大，但会波及将来 z∈(3.8,4.0) 的真命中题）/ 保持 3.3（接受真机 0.143） |
| **裁定结果** | **3.8** |
| **依据** | 用户在被告知「3.4 在冻结池全绿、真机池仍 0.143」后选定 3.8：**两池平台区分别扫描**得 冻结池 3.4 起全绿、真机池 3.62 起全绿，3.62 恰等于那道题当前的 z（贴边、下次素材微调就会再漏），3.8 留 ~0.18 余量；且平台内所有取值四个质量指标与灰区完全相同（零代价） |
| **影响面** | `tools/tool_router.py` 的 `Z_STRONG = 3.8` + 注释（两轮标定 + 两池平台区 + 纪律）；`router_bench_baseline.json` 与 `router_bench_regressions.json` 的 `baseline_metrics` 按 3.8 同步（冻结池全绿）；**新增纪律**：改阈值必须**两个口径都跑**——冻结池够不代表真机够（本次就踩过） |

> 这两条与裁定 3 的关系：**裁定 3 的 3.3 与裁定 5 的 3.8 不是矛盾，是同一序列的第二轮**（3.3 = 收口后、3.8 = 素材批同批落地）；3.3 从未进过素材批之后的运行态。

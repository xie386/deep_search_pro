## 这一版带来什么

> 一句话主线：让 Agent 从「会答」变成「**会动手，而且手是受控的**」——
> 工作目录看得见、改得动；写能力分两种、各守各的规矩；常用流程可以固定下来一步步跑；网页上的文件能真的下到你的工作目录里。

### 一、评测与结论更可核对（大点 01）

同一套问题、同一套工具池，跑出来的结论**能复跑、能对账**；评测与路由测评用同一把尺子，数字不再各说各话。

### 二、决策更稳、更省（大点 02）

候选工具咬得紧时，会再请决策模型复核一次顺序；咬得松就不折腾。该用的工具更常排到前面，不必为保险塞一堆工具进提示词 —— 同样的答案更省 token。缓存与开关按账号，随时可关。

### 三、账号路由测评看得见（大点 03）

「为什么这次没调那个工具？」现在有地方可查：账号级的路由测评页面能看到池子里有什么、题目怎么打分、哪个环节掉了链子。

### 四、数据归口、设置集中、邮件可用（大点 04）

用户数据统一收在 `user_data/` 下、路径只有一处来源；设置页补齐账号安全（绑定邮箱 + 注销）、开关与参数、邮件通道；密钥规矩统一为「名字进库、值进 .env」——备份数据库不会顺手把密钥备份出去。

### 五、文档与配置对新手更友好（大点 04 补）

两份「宪法」（版本文档规范 · 代码与数据口径）把规则写在一处；新电脑 `cp .env.example .env` 后按提示填即可跑。

### 六、网搜从「一种搜法」变成「三种取法」（大点 05）

| 你要什么 | 它怎么做 |
|---|---|
| 只想快速了解 | **只检索**，不进站 |
| 已经给了网址 | **只进站**，把那一页啃下来 |
| 知道大概在哪、但没地址 | **先检索定位，再进站深抓**（最多 1~2 个站） |

取法由工具签名固定（「只进站」那个工具根本没有查询词），不靠模型自觉；每轮检索次数也有代码闸兜底。

### 七、工作目录：看得见、改得动（大点 06）

左边栏多了「📁 工作目录」：

- 默认一条「**主页**」指向你这个账号自己的目录，也可以再加若干个真实目录；
- **逐层点进去**，文件夹、文件、体积一目了然；
- **能直接编辑**文本文件并保存；docx/xlsx 只读预览，PDF 只下载；
- **删除进回收站**，可原位还原；删回收站里的东西才是真删；
- 受保护的文件（如记忆文件）你能改、Agent 改不动；保护名单本身可改但删不掉（删了会让所有写入被拦死）；
- 带密钥字样的文件会标出来，**只提示、不给你看内容**。

### 八、写能力分两种，各守各的规矩（大点 06）

| 类型 | 举例 | 怎么用 |
|---|---|---|
| **内置写工具** | 在工作目录里建文件、改文件、删文件 | **直接用人话**，不用任何额外操作 |
| **自配来源的写能力** | 你接的 CLI 写命令、API/MCP 的写工具 | 必须在输入框用 **`/` 选中**那一套「写工具集」，**只对这一轮生效** |

用起来会感觉到的几个设计：写工具集（含里面的只读命令）**平时不进模型提示词**，你不选它就当不知道；「/」菜单三组连成一条（技能 → 写工具集 → 流程），上下键一路选过去；每条回答右下角标出这一轮用了什么，刷新后还在。

### 九、流程可以固定下来（大点 06）

「workflows」是**步骤固定**的流程：第 1 步做完、校验产出，再放第 2 步；某步失败停在那一步、不跳步。

- 在「技能与 workflows」页签里写、改、删；用的时候在输入框敲 `/` 选一个（一次一个）；
- 流程要用写能力时，在开头声明一次（`write:`），整轮就都授权了；
- 提示：**超过 5 步**的流程建议换「上游允许连接更久」的模型，否则单步容易在等结果时被掐断。

### 十、网页上的文件，真的能下到工作目录（大点 07）

对它说「去这个网站，把某张图/某个附件下下来」，它会：

1. 打开页面、点到下载（有分辨率或格式弹窗就先替你选一个）；
2. 文件落进**你这个账号的工作目录** `_downloads/browser_<时间戳>/`，左栏能逐级点开；
3. 回答里告诉你**下载了什么**（文件名 + 体积）；如果是图片，还会**直接把图显示在对话里**。

> 命令行里的 `curl` 只允许抓文本、不允许写文件（安全设计），所以「用 curl 下载」不是正路 —— 让浏览任务去点下载才对。

## 升级与兼容

- **需要重启**桌面壳 / 后端（改动集中在后端与前端外壳）；
- 旧数据不动：账号、会话、画像、技能、CLI 配置、知识库都沿用，启动时自动补齐新增字段；
- 新增设置项集中在「设置」页：工作目录与「/」唤起组（三个上限）、浏览器抓取组；
- 密钥仍只放 `.env`，界面里不回显。

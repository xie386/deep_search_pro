# 06 · 测试清单（bug 维护与优化阶段）

> **这份文件是什么**：大点 06「Agent 工作目录前端可编辑可视化与写能力开发」进入**阶段 5（bug 修复与优化）**时的**逐项测试清单**。
> 依据 [`版本文档规范.md`](../版本文档规范.md) §二补之二 阶段 5 的硬约束：
> **先「脚本自测」（单测 / harness / 离线自检）→ 再「实际客户端测试」（真机点一遍），两步都不许跳**；两步结果都要记。
>
> **它不是什么**：不是 `Done/` 的实现记录（那两份阶段 6 才写）；不承载进度（进度真值在 `v4.0规划文档.md` 目录表）。
> 测试**项数**只在阶段 6 的 `Done/06-*·实现记录.md` 里写一次，本文件用勾选框推进。

## 怎么用这份清单

1. 按 A 段跑脚本（可以要求助手一键复跑）；把**实际输出**填到「实际」列。
2. 按 B 段在**桌面壳**里逐项点；每项都要「操作 → 期望 → 实际 → 通过/不通过」。
3. 任何一项不通过：就地记下现象 + 截图，**回阶段 4 改**（规范允许），改完从该项重测。
4. C 段是**已知问题与待决项**，本阶段一并盯；D 段是结果记录口径。

**环境纪律（每条都踩过坑）**

- 跑脚本一律显式用 `.venv/Scripts/python.exe`，并先 `unset PYTHONPATH`（终端裸 `python` 是助手自己的 3.14）。
- **禁** `uv add` / `uv sync`（会整批卸掉不在 lock 的手动包：torch、chromadb、pywebview 等）；装包用 `uv pip install` + `uv pip check`。
- 真机测试**优先用你已开着的服务**（桌面壳默认 8123）；助手自起实例用 **8131** 避开，用毕即 kill。
- **写操作绝不碰真实账号**：走临时账号（`t_*` 前缀）+ 用**库副本**（`PERSONAL_DB_PATH` 指向副本）；用毕删号删目录。
- 改 `.env` 前先 `.env.bak_<时间戳>`；改用户数据前先备份到 `docs/v4.0/backups/`（不入库）。
- 本机 HTTP / CDP / WebSocket 一律绕系统代理（`--noproxy '*'`、`NO_PROXY=127.0.0.1,localhost,::1`）。
